# 01 · Concept

## Un fil, 6 étages

Imagine un immeuble du temps. Chaque étage raconte une grande période.
On visite **un étage à la fois**, avec **5 à 10 événements maximum**.

| Étage | Ce qu'on y découvre |
|---|---|
| 1. Univers | Le Big Bang, les premières étoiles, les galaxies |
| 2. Terre | La naissance du Soleil et de notre planète |
| 3. Vie | Les premières cellules, les dinosaures, les fleurs |
| 4. Humains | Nos ancêtres, le feu, les premiers *Homo sapiens* |
| 5. Histoire | L'écriture, les grandes civilisations, les découvertes |
| 6. Aujourd'hui | Le monde récent, jusqu'à nous |

## Le parcours d'un visiteur, en 5 étapes

1. **Arrivée** — une phrase d'accueil, un bouton « Commencer ». Rien d'autre.
2. **Premier étage** — l'Univers s'affiche, avec quelques points sur le fil.
3. **Ouvrir une carte** — un clic sur un point ouvre **une seule** carte. Une autre carte ? L'ancienne se ferme.
4. **Changer d'étage** — on fait défiler la page (doigt, molette, clavier). Chaque étage remplit l'écran et la page s'y arrête toute seule.
   Dans un étage, la **ligne du temps est plus large que l'écran** : on la fait glisser de côté, ou on bouge le **curseur de la loupe**. Le menu « Aller à une période » emmène directement à une période. Chaque période est **à l'échelle** ; entre deux périodes, un symbole // signale que l'échelle change.
5. **Repère d'échelle** — l'**année cosmique** est une seule règle verticale, fixe sur le côté droit de l'écran, pour tous les étages. Son curseur suit l'époque regardée. Chaque étage a en plus sa **loupe** (« si … tenait en un an »), avec un curseur qu'on fait glisser.

## Idées ludiques

**Indispensable**
- Des catégories dans chaque étage (périodes, espèces humaines, histoire du christianisme…), choisies dans un menu déroulant : une seule catégorie affichée à la fois.
- Le repère « si l'univers tenait en un an » (le calendrier cosmique).
- Une animation douce quand on change d'étage (désactivable).

**Plus tard**
- D'autres grands thèmes dans l'étage Histoire : sciences, arts, autres religions.
- Un petit quiz de 3 questions à la fin d'un étage.
- Une visite guidée qui enchaîne les cartes toute seule.
- Une version hors ligne pour les musées.
- Un lien vers l'Arbre du vivant depuis l'étage « Vie ».

**Abandonné**
- Les cartes et descriptions écrites par IA.
- Les calques superposés (religions, guerres, arts…) affichés en même temps.
- Les annotations, l'export d'image et les barres d'outils chargées.
