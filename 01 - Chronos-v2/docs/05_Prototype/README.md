# 05 · Prototype

## Le code viendra plus tard

Ce dossier est vide pour l'instant, et c'est voulu.
On construit d'abord les fondations (la vision, le design, les contenus), puis la maison.

## La technologie prévue

- **React** — une boîte à outils pour construire des pages interactives, morceau par morceau.
- **Vite** — l'outil qui transforme notre code en site rapide.
- **Vercel** — le service qui met le site en ligne, gratuitement, à chaque nouvelle version.

La frise sera faite en **HTML** (le langage de base des pages web) : le clavier et
les lecteurs d'écran la comprennent. Les effets (profondeur, parallaxe, animations)
viendront par-dessus, et se couperont si l'appareil demande moins de mouvement.
