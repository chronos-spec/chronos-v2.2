# 03 · Contenus

## Comment écrire une carte

Une carte, c'est un petit moment d'émerveillement. Elle contient :

1. **Un titre court** — 5 mots maximum.
2. **Une date lisible** — « il y a 13,8 milliards d'années », pas « 13 787 Ma ».
3. **3 phrases maximum** — une pour dire *quoi*, une pour dire *pourquoi c'est important*, une pour étonner.
4. **Une image** — libre de droits, avec son auteur. Une vraie photo si elle existe, sinon une illustration.
5. **Une source** — où l'on a vérifié l'information.

Astuce : lis ta carte à voix haute. Si tu butes, raccourcis.

## La règle d'or

**Chaque fait doit avoir une source fiable.**
Sources fiables : musées (Muséum national d'Histoire naturelle…), agences spatiales (NASA, ESA),
revues scientifiques (*Nature*, *Science*), manuels universitaires.
Pas fiable seul : un blog, une vidéo, une réponse d'IA.
Quand les scientifiques ne sont pas d'accord, on le dit simplement : « environ », « peut-être ».

## Le modèle de fiche à copier

```markdown
### [Titre court]
- **Étage** : Univers / Terre / Vie / Humains / Histoire / Aujourd'hui
- **Date** : il y a …
- **Calendrier cosmique** : le … à … h …
- **Texte** : (3 phrases maximum)
- **Image** : [description] — auteur, licence, lien
- **Source** : auteur, titre, année, lien
- **Vérifié le** : JJ/MM/AAAA
```

Les exemples sont dans `evenements-modele.md`.
