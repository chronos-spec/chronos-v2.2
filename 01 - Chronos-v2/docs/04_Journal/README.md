# 04 · Journal

## À quoi sert le journal ?

C'est la mémoire du projet. Dans six mois, on aura oublié **pourquoi** on a choisi telle couleur
ou abandonné telle idée. Le journal s'en souvient pour nous.

Il évite aussi de refaire deux fois la même erreur ou le même débat.

## Comment écrire une entrée

Une entrée par séance de travail, **la plus récente en haut**. Quatre rubriques :

```markdown
## JJ mois AAAA — Titre court

**Ce qui a été fait**
- …

**Décisions prises**
- … (et pourquoi, en une phrase)

**Questions ouvertes**
- …
```

## Les règles

- Court : 10 lignes suffisent.
- Honnête : on note aussi ce qui n'a pas marché.
- On ne réécrit jamais une ancienne entrée. Si on change d'avis, on écrit une nouvelle entrée.

Le journal lui-même est dans `journal.md`.
